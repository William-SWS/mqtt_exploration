# Já programa em Python e conhece machine learning

O aprendiz declarou conhecimento prévio de Python e machine learning (profundidade não detalhada) e quer revisar como se fosse do zero para fixar. As aulas explicam cada conceito novo da stack (uv, YAML seguro, manifesto, integridade), mas recapitulam em uma linha o que é Python básico (funções, f-strings, `pathlib`) em vez de ensinar a sintaxe.
